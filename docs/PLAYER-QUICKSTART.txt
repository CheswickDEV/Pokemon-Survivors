POKEMON SURVIVORS 1.0.0-rc.6.5 — LOCAL PLAYER TEST BUILD

1. Right-click the ZIP and choose Extract All.
2. Double-click "Start game.cmd" in the extracted folder.
3. Your browser opens http://127.0.0.1:4173/
4. Choose your partner, trainer, run mode and difficulty.
5. English is the default. Select Deutsch in camp or Settings for German.

No installation, administrator access or internet is needed to play.
The unmodified runtime is included under runtime/.
For Windows 10/11 on x64 with current Edge or Chrome.
Keyboard and mouse required; touch/gamepad are not supported yet.

Keep the launch window open. After "Save & return to camp", close it or
press Ctrl+C. A second launch detects a running copy. If another program
uses port 4173, the launcher does not terminate it.

CONTROLS
WASD / arrows: move. Space: dodge. E: interact.
Tab: team / evolutions. M: map. Esc: pause / save.
The game continues when switching windows. Press Esc to pause.

SAVES
Forest, Kanto and Boss Rush have separate save slots.
Choose "Back up everything" in camp or "Back up all saves & profile"
while paused. The JSON file also includes your Pokedex and settings.
Import it when moving to another browser.
Clearing browser data or changing browser/address uses different storage.
Replacing the game folder does not delete browser saves.
Still, export a complete backup before updating.

TROUBLESHOOTING
No browser window: open http://127.0.0.1:4173/ manually.
Port busy: close your previous game launch window, then try again.
Missing files: extract the entire ZIP into a new folder.
Missing images: reload the browser; do not double-click dist/index.html.
Windows download warning: the overall package has no additional installer
signature. Do not disable security features.
